# Avinash Kumar — Portfolio Website

A responsive personal portfolio with a black and green theme, smooth reveal animations, mobile navigation, and sections for About, Skills, Projects, Education, and Contact.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish your site.

## Update details
Edit `index.html` to change text, links, education, or projects. Edit `style.css` to change the design.
