# Simple Calculator

A beginner-level calculator project made with **HTML, CSS and JavaScript**. It performs basic arithmetic operations through a clean, responsive interface.

> **Student project:** Avinash Kumar  
> **Course:** BCA, Semester 3  
> **Project type:** Front-end mini project

## Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Percentage calculation
- Clear (`AC`) and delete (`DEL`) buttons
- Keyboard support
- Division-by-zero message
- Responsive layout for mobile and desktop
- No JavaScript `eval()` function is used

## Technologies used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and calculator buttons |
| CSS3 | Layout, colors, responsive design and button styling |
| JavaScript | Input handling and calculation logic |

## How to run the project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it with a browser.
4. Start using the calculator.

No installation or build command is required.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `0`–`9` | Enter a number |
| `+`, `-`, `*`, `/` | Select an operation |
| `.` | Decimal point |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last digit |
| `Escape` | Clear calculator |

## Learning outcomes

By building this project, I practised connecting an HTML page with CSS and JavaScript, selecting elements from the DOM, handling click and keyboard events, using functions and conditional statements, and testing common calculation cases.
